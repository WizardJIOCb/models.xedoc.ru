# Character asset licenses

## Quaternius CC0 collection

The following embedded GLB previews were adapted from free character packs by
Quaternius (`@Quaternius`):

- `sun_cleric`, `stone_monk`, `wild_ranger`, `dusk_rogue`, `iron_warrior`,
  `arcane_sage` — [RPG Character Pack](https://quaternius.com/packs/rpgcharacters.html)
- `golden_sentinel`, `hedge_witch`, `plaguebound` —
  [Ultimate Animated Character Pack](https://quaternius.com/packs/ultimatedanimatedcharacter.html)

The source packs are dedicated to the public domain under
[CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/).
The Kimodo versions rename the humanoid bones, normalize skin weights, embed
the supplied color textures, and correct legacy FBX alpha values.

Credit is not required by CC0, but is included here with thanks to Quaternius.
